# Hello World

When this skill is invoked, greet the user warmly.

## Instructions

1. Say "Hello, world! 👋" to the user.
2. If the user provided a name as an argument, greet them by name instead, e.g. "Hello, Ada! 👋".
3. Briefly confirm that the skill loaded and ran successfully.

## Example

User: /hello-world
Response: Hello, world! 👋 The hello-world skill is working.

User: /hello-world Ada
Response: Hello, Ada! 👋 The hello-world skill is working.
